# Implementační plán V1 – Kinotéka

Rozsah: [SCOPE.md](SCOPE.md) · Mockupy: [docs/mockupy/index.html](docs/mockupy/index.html)

Každý přírůstek je samostatně spustitelný a ověřitelný. Další přírůstek začíná až po potvrzení, že předchozí funguje.

## Krok 4 – Repo + CI (před prvním přírůstkem)

- Kostra electron-vite + React + TypeScript (strict), ESLint, Prettier, Vitest.
- Prázdné okno „Kinotéka“ s bezpečným nastavením (izolovaný kontext, bez Node v UI).
- GitHub Actions na `windows-latest`: lint → kontrola typů → testy → build.
- **Ověření:** CI na GitHubu je zelené; `npm run dev` otevře prázdné okno aplikace.
